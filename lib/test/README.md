# Test dependencies

- [JUnit 4.13.1](https://repo.maven.apache.org/maven2/junit/junit/4.13.1/) provides the test annotations, assertions, and runner.
- [Hamcrest Core 1.3](https://repo.maven.apache.org/maven2/org/hamcrest/hamcrest-core/1.3/) is JUnit's runtime dependency.

The original JARs and their license notices are included for offline test runs.
The linked Maven Central directories contain the matching source archives.
The application build uses only the JDK.
